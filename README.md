# 10-K 분석 기업 선정

## 선택 기업

**KLA Corporation (KLAC)**

## 선정 이유

AI와 고성능 반도체 시장이 성장하면서 관련 기업들을 찾아보던 중 KLA에 관심을 가지게 되었다.

KLA는 반도체를 직접 생산하는 기업은 아니지만, 반도체가 제대로 만들어지고 있는지 검사하고 아주 작은 결함을 찾아내는 장비와 기술을 제공한다. 반도체가 점점 작아지고 구조가 복잡해질수록 제조 과정에서 발생하는 결함을 정확하게 찾아내는 것이 중요해지기 때문에 KLA의 기술도 함께 중요해질 수 있다고 생각했다.

특히 AI 반도체, HBM, 첨단 패키징처럼 제조 난이도가 높은 반도체의 수요가 증가하고 있다는 점에서 앞으로 KLA의 검사·계측 기술에 대한 수요도 어떻게 변화할지 궁금했다.

따라서 KLA의 10-K를 통해 현재 어떤 기술과 경쟁력을 가지고 있는지, 연구개발에 얼마나 투자하고 있는지, 실제 매출과 수요는 어떻게 변화하고 있는지를 살펴보고 앞으로의 성장 가능성을 분석해보고자 KLA를 선택하였다.
